# 📊 SQL Practice Arena


Welcome to the **SQL Practice Arena**! This repository is a dedicated workspace built to sharpen database query skills, ranging from fundamental data manipulation to advanced performance optimization.

---

## 🎯 Repository Objectives
* **Master Complex Queries:** Deep dive into multi-table JOINs, window functions, and CTEs.
* **Schema Design:** Practice building efficient Entity-Relationship (ER) models.
* **Performance Tuning:** Learn query optimization using indexes and execution plans.

---

## 📂 Repository Structure

```text
├── 01-Foundations/          # Basic CRUD, Filtering (WHERE), Sorting (ORDER BY)
├── 02-Intermediate/         # Aggregate Functions, GROUP BY, Standard JOINs
├── 03-Advanced/             # Window Functions, CTEs, Subqueries, Stored Procedures
├── 04-Real-World-Case/      # E-commerce, Finance, and HR Mock Data analytics
└── README.md                # Project documentation
```

## 🚀 How to Use This Repo

### 1. Prerequisites
Ensure you have an IDE or Database client installed:
* [MySQL Workbench](https://mysql.com)
* [pgAdmin](https://pgadmin.org) (for PostgreSQL)
* [DBeaver](https://dbeaver.io) (Universal Database Tool)

### 2. Getting Started
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. Navigate to any directory (e.g., `01-Foundations/`).
3. Load the corresponding sample dataset script into your SQL client.
4. Execute the challenge queries and check your results!

## 💡 SQL Cheat Sheet Highlight

### The Logical Order of Query Execution
Understanding this loop helps write bug-free queries faster:

```text
🔄 FROM ➡️ JOIN ➡️ WHERE ➡️ GROUP BY ➡️ HAVING ➡️ SELECT ➡️ DISTINCT ➡️ ORDER BY ➡️ LIMIT
```
